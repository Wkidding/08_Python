# 第1章 计算机与程序设计概述


## 1.1 计算机体系结构基础

计算机体系结构是理解程序如何运行的基础。现代计算机遵循 **冯·诺依曼体系结构**（Von Neumann Architecture），其核心思想是 **存储程序**（Stored Program Concept）——将指令和数据以二进制形式存储在内存中，由中央处理器（CPU）按顺序读取并执行。

### 核心组件

| 组件                  | 功能                                                         |
| --------------------- | ------------------------------------------------------------ |
| **中央处理器（CPU）** | 执行算术、逻辑运算和控制指令，包含算术逻辑单元（ALU）和控制单元（CU） |
| **内存（主存）**      | 存储正在运行的程序和数据（RAM，断电即失）                    |
| **存储设备**          | 持久化保存数据（硬盘、SSD）                                  |
| **输入设备**          | 向计算机输入数据（键盘、鼠标）                               |
| **输出设备**          | 输出计算结果（显示器、打印机）                               |

### CPU 执行周期

1. **取指（Fetch）**：从内存中读取下一条指令
2. **译码（Decode）**：解释指令的含义
3. **执行（Execute）**：执行操作（如加法、比较）
4. **写回（Write Back）**：将结果写回寄存器或内存

```python
# Python 模拟一个简化的指令执行（仅示意）
class SimpleCPU:
    def __init__(self):
        self.registers = {'A': 0, 'B': 0}
        self.memory = [0] * 256
        self.pc = 0  # 程序计数器

    def fetch(self):
        instruction = self.memory[self.pc]
        self.pc += 1
        return instruction

    def execute(self, opcode, operand):
        if opcode == 'ADD':
            self.registers['A'] += operand
        elif opcode == 'MOV':
            self.registers['B'] = operand
        # ... 省略其他指令

    def run(self):
        while self.pc < len(self.memory):
            instr = self.fetch()
            # 解析并执行...
            break

print("CPU 模拟示意（仅概念）")
```

> **关键理解**：程序本质上就是存储在内存中的二进制指令序列，CPU 通过「取指-译码-执行」的循环不断运行。


## 1.2 程序在计算机中的执行过程

一个程序从源代码到最终在硬件上执行，通常经历以下阶段（以 Python 为例，但本质类似编译型语言）：

### 传统编译型语言（C/C++）的执行流程

1. **预处理** → 2. **编译**（源代码 → 汇编代码） → 3. **汇编**（汇编 → 机器码） → 4. **链接**（生成可执行文件） → 5. **加载到内存** → 6. **CPU 执行**

### Python 的执行流程（解释型）

Python 是 **解释型语言**，但仍需编译为中间字节码，再由虚拟机执行：

1. **源代码**（`.py` 文件）
2. **词法/语法分析** → 生成 **抽象语法树（AST）**
3. **编译** → 生成 **字节码**（`.pyc` 文件，存储在 `__pycache__`）
4. **Python 虚拟机（PVM）** 读取字节码并逐条解释执行

```python
# 查看 Python 字节码（使用 dis 模块）
import dis

def add(a, b):
    return a + b

print("add 函数的字节码：")
dis.dis(add)
# 输出示例：
#  2           0 LOAD_FAST                0 (a)
#              2 LOAD_FAST                1 (b)
#              4 BINARY_OP                0 (+)
#              8 RETURN_VALUE
```

> **理解**：Python 并非纯解释型，而是「编译为字节码 + 解释执行」的混合模式，这与 Java 的 JVM 类似。

### 内存中的程序布局

当程序运行时，操作系统为其分配内存空间，通常分为：

- **代码段**：存储机器指令
- **数据段**：存储全局变量和静态变量
- **堆（Heap）**：动态分配的内存（如 Python 对象）
- **栈（Stack）**：存储函数调用信息、局部变量


## 1.3 编程语言的发展与 Python 的历史地位

### 编程语言演化简史

| 时代        | 代表语言                     | 特点                               |
| ----------- | ---------------------------- | ---------------------------------- |
| 1940s–1950s | 机器语言（二进制）           | 直接面向硬件，难以阅读和编写       |
| 1950s–1960s | 汇编语言                     | 助记符替代二进制，但仍依赖硬件     |
| 1960s–1970s | Fortran, COBOL, C            | 高级语言，面向过程和系统编程       |
| 1980s–1990s | C++, Java, Python            | 面向对象，跨平台，大幅提升开发效率 |
| 2000s–至今  | Python, JavaScript, Go, Rust | 多范式，重视开发效率和安全性       |

### Python 的历史与定位

- **创始人**：Guido van Rossum（吉多·范罗苏姆）
- **诞生**：1989 年（圣诞假期期间），作为 ABC 语言的改进项目
- **命名**：取自英国喜剧团体 Monty Python（非指蟒蛇）
- **版本里程碑**：
  - **Python 2.0**（2000）：加入垃圾回收、列表推导等
  - **Python 3.0**（2008）：打破向后兼容，统一字符编码，简化语法
  - **Python 3.6**（2016）：f-string、类型注解等
  - **Python 3.11+**（2022+）：性能显著提升

**Python 的适用领域**：Web 开发（Django/Flask）、数据科学（NumPy/Pandas）、人工智能（PyTorch/TensorFlow）、自动化脚本、科学计算等。

### 为什么 Python 如此流行？

- **语法简洁**：接近自然语言，学习曲线平缓
- **跨平台**：Windows / Linux / macOS 均可运行
- **丰富的第三方库**：PyPI 拥有超过 40 万个包
- **社区活跃**：大量教程、文档和支持
- **“胶水语言”**：可调用 C/C++/Fortran 等底层库，兼顾性能


## 1.4 Python 的设计哲学（Zen of Python）

Python 的设计哲学体现在 **PEP 20**（Python Enhancement Proposal 20），也称为 **Zen of Python**（Python 之禅）。在 Python 交互式环境中输入 `import this` 即可查看。

```python
import this

# 输出内容（中英对照核心条目）：
# Beautiful is better than ugly.        —— 优美胜于丑陋
# Explicit is better than implicit.     —— 明了胜于晦涩
# Simple is better than complex.        —— 简洁胜于复杂
# Complex is better than complicated.   —— 复杂胜于凌乱
# Flat is better than nested.           —— 扁平胜于嵌套
# Sparse is better than dense.          —— 稀疏胜于密集
# Readability counts.                   —— 可读性很重要
# Special cases aren't special enough to break the rules.
# Although practicality beats purity.   —— 实用性胜过纯粹性
# Errors should never pass silently.
# Unless explicitly silenced.
# In the face of ambiguity, refuse the temptation to guess.
# There should be one-- and preferably only one --obvious way to do it.
# Now is better than never.
# Although never is often better than *right* now.
# If the implementation is hard to explain, it's a bad idea.
# If the implementation is easy to explain, it may be a good idea.
# Namespaces are one honking great idea -- let's do more of those!
```

这些原则深刻影响了 Python 的语法设计，例如强制缩进、强调可读性、提供一种明显的做法（而非多种混乱的做法）。

```python
# 哲学在编码中的体现：优先使用清晰明确的写法

# ❌ 过于晦涩（虽然能工作）
result = [x for x in range(10) if x%2==0]  # 列表推导没问题，但过度嵌套会难读

# ✅ 可读性更好
even_numbers = []
for x in range(10):
    if x % 2 == 0:
        even_numbers.append(x)
```


## 1.5 Python 解释器与运行环境

Python 代码需要由**解释器**（Interpreter）执行。主流实现有：

| 解释器         | 说明                                               | 适用场景                   |
| -------------- | -------------------------------------------------- | -------------------------- |
| **CPython**    | 官方参考实现，用 C 语言编写，最常用。              | 绝大多数开发和生产环境     |
| **PyPy**       | 使用 JIT（即时编译）技术，执行速度快，但启动较慢。 | 需要高性能的长期运行程序   |
| **Jython**     | 运行在 Java 虚拟机（JVM）上，可与 Java 库互操作。  | 需要与 Java 代码集成的场景 |
| **IronPython** | 运行在 .NET CLR 上，可与 C# 等语言互操作。         | 需要与 .NET 环境集成       |

**如何查看当前解释器？**

```python
import sys
print(sys.implementation.name)  # 通常是 'cpython'
print(sys.version)              # 版本详情
print(sys.platform)             # 操作系统平台
```

> 多数情况下，我们直接使用 CPython。Python 3 是当前主流，Python 2 已于 2020 年停止维护。


## 1.6 开发环境搭建（IDLE / VS Code / PyCharm）

## 1.7 第一个 Python 程序："Hello World" 逐行解析

### 代码

```python
# hello.py
print("Hello, World!")
```

### 逐行分析

| 部分              | 说明                                                         |
| ----------------- | ------------------------------------------------------------ |
| `# hello.py`      | 单行注释，以 `#` 开头，解释器忽略                            |
| `print()`         | 内置函数，将内容输出到控制台                                 |
| `"Hello, World!"` | 字符串字面量，用双引号包围（也可用单引号）                   |
| 无分号            | Python 语句不需要分号结束（若有多个语句在一行，可用分号分隔，但不推荐） |

### 更完整的示例（展示 Python 语法风格）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
第一个完整的 Python 程序
演示注释、导入、函数、变量和输出
"""

import sys

def main():
    """程序入口函数"""
    name = "World"          # 变量赋值
    greeting = f"Hello, {name}!"  # f-string 格式化
    print(greeting)
    print(f"Python 版本: {sys.version}")

if __name__ == "__main__":
    main()
```

**运行方式**：
- 保存为 `hello.py`
- 终端执行 `python hello.py`
- 输出：`Hello, World!` 以及版本信息


## 1.8 交互式环境与脚本执行

Python 提供两种执行模式：**交互式**（REPL）和 **脚本式**。

### 交互式环境（REPL：Read-Eval-Print Loop）

- 在终端输入 `python`（或 `python3`）进入
- 每输入一条语句，立即执行并显示结果
- 适合快速测试、学习语法、调试

```python
# 在终端输入 python 后：
>>> 3 + 5
8
>>> name = "Python"
>>> name.upper()
'PYTHON'
>>> import math
>>> math.sqrt(16)
4.0
>>> exit()   # 或 Ctrl+D（Unix）/ Ctrl+Z（Windows）
```

### 交互式环境的便捷功能

- `_`（下划线）保存上一次表达式的计算结果
- 使用 `Tab` 键补全变量名或函数名
- `help()` 查看帮助，如 `help(print)`

```python
>>> 10 * 2
20
>>> _ + 5
25
>>> import os
>>> os.<Tab>   # 按 Tab 查看补全选项
```

### 脚本执行

- 将代码保存为 `.py` 文件
- 使用 `python 文件名.py` 执行
- 也可以给脚本添加执行权限（Linux/macOS）：`chmod +x hello.py` 后 `./hello.py`

### 两种模式的对比

| 模式   | 优点               | 适用场景           |
| ------ | ------------------ | ------------------ |
| 交互式 | 即时反馈，适合探索 | 实验、学习、调试   |
| 脚本式 | 可复用、可自动化   | 编写实际程序、项目 |

### 交互式环境中执行脚本（`-i` 选项）

```bash
python -i hello.py   # 执行脚本后进入交互模式，可继续操作变量
```

### Python 的 `__main__` 约定

每个 Python 模块都有一个 `__name__` 属性。当文件被直接执行时，`__name__` 被设为 `"__main__"`；当被导入为模块时，则为模块名。这一约定使文件既可作脚本运行，也可作为模块导入。

```python
# 示例：mymodule.py
def add(a, b):
    return a + b

if __name__ == "__main__":
    # 只有直接运行时才执行以下代码
    print("测试：", add(2, 3))
```

```bash
# 直接运行
python mymodule.py   # 输出 "测试： 5"

# 导入使用
# 在交互式环境中：import mymodule；mymodule.add(5,6) 不会打印测试信息
```

# 第十一章 面向对象编程（下）与魔术方法

## 一、魔法方法（特殊方法）总览

魔法方法（Magic Methods）又称特殊方法（Special Methods）或 dunder methods（double underscore methods），是 Python 中以双下划线开头和结尾的方法。它们由 Python 解释器在特定场景下自动调用，用于实现对象的**运算符重载**、**协议实现**和**内置行为定制**。

### (1) 对象生命周期

#### 1.1 `__new__`：创建实例

在实例创建时最先调用，负责**创建并返回**实例对象。第一个参数是 `cls`。

```python
class Singleton:
    _instance = None

    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

a = Singleton()
b = Singleton()
print(a is b)   # True
```

#### 1.2 `__init__`：初始化实例

在 `__new__` 返回实例后调用，负责**初始化**实例属性。第一个参数是 `self`，必须返回 `None`。

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

p = Person("Alice", 25)
```

#### 1.3 `__del__`：析构方法

对象被垃圾回收时调用，用于资源清理。调用时机不确定，不应用于关键资源释放。

```python
class Resource:
    def __del__(self):
        print("资源被销毁")

r = Resource()
del r   # 资源被销毁
```

#### 1.4 `__init_subclass__`：子类创建时调用

在定义子类时自动调用，常用于注册子类或验证子类。

```python
class Plugin:
    plugins = []

    def __init_subclass__(cls, **kwargs):
        super().__init_subclass__(**kwargs)
        Plugin.plugins.append(cls)

class PluginA(Plugin): pass
class PluginB(Plugin): pass

print(Plugin.plugins)   # [<class 'PluginA'>, <class 'PluginB'>]
```

#### 1.5 `__set_name__`：描述符命名时调用

描述符被赋值给类属性时调用，接收 owner 类和属性名。

```python
class Field:
    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, obj, objtype=None):
        return obj.__dict__.get(self.name)

    def __set__(self, obj, value):
        obj.__dict__[self.name] = value

class Model:
    name = Field()
    age = Field()

m = Model()
m.name = "Alice"
print(m.name)   # Alice
```

### (2) 字符串表示

#### 2.1 `__str__`：用户友好的字符串

`str(obj)`、`print(obj)`、`f"{obj}"` 时调用，返回用户可读的字符串。

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"({self.x}, {self.y})"

print(Point(1, 2))   # (1, 2)
```

#### 2.2 `__format__`：格式化字符串

`format(obj, spec)`、`f"{obj:spec}"` 时调用。

```python
class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius

    def __format__(self, spec):
        if spec == "f":
            return f"{self.celsius * 9/5 + 32:.1f}°F"
        return f"{self.celsius:.1f}°C"

t = Temperature(25)
print(f"{t}")    # 25.0°C
print(f"{t:f}")  # 77.0°F
```

#### 2.3 `__bytes__`：字节表示

`bytes(obj)` 时调用。

```python
class Message:
    def __init__(self, text):
        self.text = text

    def __bytes__(self):
        return self.text.encode("utf-8")

print(bytes(Message("hello")))   # b'hello'
```

### (3) 属性访问

#### 3.1 `__getattr__`：属性不存在时调用

只有当常规属性查找失败时才调用。

```python
class Dynamic:
    def __getattr__(self, name):
        return f"动态属性: {name}"

d = Dynamic()
print(d.foo)   # 动态属性: foo
print(d.bar)   # 动态属性: bar
```



#### 3.2 `__getattribute__`：所有属性访问时调用

每次访问属性都会调用，优先级最高。容易引发无限递归，需谨慎使用。

```python
class Demo:
    def __getattribute__(self, name):
        print(f"访问属性: {name}")
        return super().__getattribute__(name)

d = Demo()
d.x = 10
print(d.x)
# 访问属性: x
# 10
```

#### 3.3 `__setattr__`：设置属性时调用

每次设置属性都会调用。

```python
class ReadOnly:
    def __init__(self):
        object.__setattr__(self, "initialized", True)

    def __setattr__(self, name, value):
        if getattr(self, "initialized", False):
            raise AttributeError("对象是只读的")
        super().__setattr__(name, value)

r = ReadOnly()
# r.x = 10   # AttributeError: 对象是只读的
```

#### 3.4 `__delattr__`：删除属性时调用

```python
class Demo:
    def __delattr__(self, name):
        print(f"删除属性: {name}")
        super().__delattr__(name)

d = Demo()
d.x = 10
del d.x   # 删除属性: x
```

#### 3.5 `__dir__`：自定义 `dir()` 结果

```python
class Demo:
    def __dir__(self):
        return ["a", "b", "c"]

print(dir(Demo()))   # ['a', 'b', 'c']
```

### (4) 描述符协议

#### 4.1 `__get__`、`__set__`、`__delete__`

描述符用于控制属性访问，是 `property`、`classmethod`、`staticmethod` 的底层实现。

```python
class Positive:
    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return obj.__dict__.get(self.name)

    def __set__(self, obj, value):
        if value < 0:
            raise ValueError("必须为正数")
        obj.__dict__[self.name] = value

class Product:
    price = Positive()

    def __init__(self, price):
        self.price = price

p = Product(100)
print(p.price)   # 100
# p.price = -1   # ValueError
```

**分类**：

-   **数据描述符**：实现了 `__set__` 或 `__delete__`，优先级高于实例 `__dict__`。
-   **非数据描述符**：只实现 `__get__`，优先级低于实例 `__dict__`。

### (5) 容器与序列

#### 5.1 `__len__`：长度

`len(obj)` 时调用。

```python
class MyList:
    def __init__(self, data):
        self.data = data

    def __len__(self):
        return len(self.data)

print(len(MyList([1, 2, 3])))   # 3
```

#### 5.2 `__getitem__`：索引访问

`obj[key]` 时调用。

```python
class MyList:
    def __init__(self, data):
        self.data = data

    def __getitem__(self, index):
        return self.data[index]

ml = MyList([10, 20, 30])
print(ml[0])    # 10
print(ml[1:3])  # [20, 30]
```

#### 5.3 `__setitem__`：索引赋值

`obj[key] = value` 时调用。

```python
class MyList:
    def __init__(self):
        self.data = {}

    def __setitem__(self, key, value):
        self.data[key] = value

ml = MyList()
ml[0] = "a"
print(ml.data)   # {0: 'a'}
```



#### 5.4 `__delitem__`：索引删除

`del obj[key]` 时调用。

```python
class MyList:
    def __init__(self, data):
        self.data = list(data)

    def __delitem__(self, index):
        del self.data[index]

ml = MyList([1, 2, 3])
del ml[0]
print(ml.data)   # [2, 3]
```



#### 5.5 `__contains__`：`in` 运算符

`x in obj` 时调用。

```python
class MyList:
    def __init__(self, data):
        self.data = data

    def __contains__(self, item):
        return item in self.data

print(2 in MyList([1, 2, 3]))   # True
```

#### 5.6 `__iter__`：迭代器

`for x in obj` 时调用，返回迭代器。

```python
class MyList:
    def __init__(self, data):
        self.data = data

    def __iter__(self):
        return iter(self.data)

for x in MyList([1, 2, 3]):
    print(x)
```

#### 5.7 `__next__`：迭代器协议

与 `__iter__` 配合，定义迭代器的下一个值。

```python
class Countdown:
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        self.current -= 1
        return self.current + 1

for x in Countdown(3):
    print(x)   # 3 2 1
```

#### 5.8 `__reversed__`：`reversed()` 支持

```python
class MyList:
    def __init__(self, data):
        self.data = data

    def __reversed__(self):
        return reversed(self.data)

print(list(reversed(MyList([1, 2, 3]))))   # [3, 2, 1]
```

#### 5.9 `__missing__`：字典缺失键

用于 `dict` 的子类，当键不存在时调用。

```python
class DefaultDict(dict):
    def __missing__(self, key):
        return f"默认值({key})"

d = DefaultDict()
print(d["a"])   # 默认值(a)
```



### (6) 比较运算

#### 6.1 比较运算符

| 方法     | 运算符 |
| :------- | :----- |
| `__eq__` | `==`   |
| `__ne__` | `!=`   |
| `__lt__` | `<`    |
| `__le__` | `<=`   |
| `__gt__` | `>`    |
| `__ge__` | `>=`   |

python

```python
class Version:
    def __init__(self, major, minor):
        self.major = major
        self.minor = minor

    def __eq__(self, other):
        return (self.major, self.minor) == (other.major, other.minor)

    def __lt__(self, other):
        return (self.major, self.minor) < (other.major, other.minor)

v1 = Version(1, 0)
v2 = Version(2, 0)
print(v1 == v2)   # False
print(v1 < v2)    # True
print(v1 != v2)   # True（自动取反）
```



#### 6.2 `__hash__`：哈希值

用于 `hash(obj)`、集合、字典键。定义 `__eq__` 后，`__hash__` 会被设为 `None`，需显式定义。

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __eq__(self, other):
        return (self.x, self.y) == (other.x, other.y)

    def __hash__(self):
        return hash((self.x, self.y))

p1 = Point(1, 2)
p2 = Point(1, 2)
print(hash(p1) == hash(p2))   # True
print({p1, p2})               # {Point(1, 2)}
```



#### 6.3 `__bool__`：布尔值

`bool(obj)`、`if obj:` 时调用。

```python
class MyList:
    def __init__(self, data):
        self.data = data

    def __bool__(self):
        return len(self.data) > 0

print(bool(MyList([])))       # False
print(bool(MyList([1, 2])))   # True
```



### (7) 算术运算

#### 7.1 二元算术运算符

| 方法           | 运算符     |
| :------------- | :--------- |
| `__add__`      | `+`        |
| `__sub__`      | `-`        |
| `__mul__`      | `*`        |
| `__truediv__`  | `/`        |
| `__floordiv__` | `//`       |
| `__mod__`      | `%`        |
| `__pow__`      | `**`       |
| `__matmul__`   | `@`        |
| `__divmod__`   | `divmod()` |



```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, scalar):
        return Vector(self.x * scalar, self.y * scalar)

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)      # Vector(4, 6)
print(v1 * 3)       # Vector(3, 6)
```

#### 7.2 反向算术运算符

当左操作数不支持运算时，Python 尝试右操作数的反向方法。

| 方法       | 运算符      |
| :--------- | :---------- |
| `__radd__` | `+`（反向） |
| `__rsub__` | `-`（反向） |
| `__rmul__` | `*`（反向） |
| ...        | ...         |



```python
class Vector:
    def __init__(self, x):
        self.x = x

    def __radd__(self, other):
        print("调用 __radd__")
        return Vector(other + self.x)

    def __repr__(self):
        return f"Vector({self.x})"

v = Vector(10)
print(5 + v)   # 调用 __radd__ -> Vector(15)
```

#### 7.3 增量赋值运算符

| 方法       | 运算符 |
| :--------- | :----- |
| `__iadd__` | `+=`   |
| `__isub__` | `-=`   |
| `__imul__` | `*=`   |
| ...        | ...    |



```python
class Counter:
    def __init__(self, value=0):
        self.value = value

    def __iadd__(self, other):
        self.value += other
        return self

    def __repr__(self):
        return f"Counter({self.value})"

c = Counter(10)
c += 5
print(c)   # Counter(15)
```



#### 7.4 一元运算符

| 方法         | 运算符            |
| :----------- | :---------------- |
| `__neg__`    | `-obj`            |
| `__pos__`    | `+obj`            |
| `__abs__`    | `abs(obj)`        |
| `__invert__` | `~obj`            |
| `__round__`  | `round(obj)`      |
| `__floor__`  | `math.floor(obj)` |
| `__ceil__`   | `math.ceil(obj)`  |
| `__trunc__`  | `math.trunc(obj)` |



```python
class Number:
    def __init__(self, value):
        self.value = value

    def __neg__(self):
        return Number(-self.value)

    def __abs__(self):
        return Number(abs(self.value))

    def __repr__(self):
        return f"Number({self.value})"

n = Number(-5)
print(-n)      # Number(5)
print(abs(n))  # Number(5)
```

### (8) 类型转换

| 方法          | 用途                                        |
| :------------ | :------------------------------------------ |
| `__int__`     | `int(obj)`                                  |
| `__float__`   | `float(obj)`                                |
| `__complex__` | `complex(obj)`                              |
| `__bool__`    | `bool(obj)`                                 |
| `__bytes__`   | `bytes(obj)`                                |
| `__index__`   | 用于切片、`bin()`、`hex()` 等，必须返回整数 |
| `__round__`   | `round(obj)`                                |



```python
class Fraction:
    def __init__(self, numerator, denominator):
        self.numerator = numerator
        self.denominator = denominator

    def __float__(self):
        return self.numerator / self.denominator

    def __int__(self):
        return self.numerator // self.denominator

f = Fraction(7, 2)
print(float(f))   # 3.5
print(int(f))     # 3
```



### (9) 上下文管理器

#### 9.1 `__enter__` 与 `__exit__`

用于 `with` 语句，实现资源自动管理。

```python
class FileHandler:
    def __init__(self, filename, mode):
        self.filename = filename
        self.mode = mode
        self.file = None

    def __enter__(self):
        self.file = open(self.filename, self.mode)
        return self.file

    def __exit__(self, exc_type, exc_val, exc_tb):
        if self.file:
            self.file.close()
        # 返回 False 表示不抑制异常
        return False

with FileHandler("test.txt", "w") as f:
    f.write("Hello")
```

**`__exit__` 参数**：

-   `exc_type`：异常类型，无异常时为 `None`。
-   `exc_val`：异常实例。
-   `exc_tb`：异常回溯对象。
-   返回 `True` 表示抑制异常，`False` 表示传播异常。



#### 9.2 异步上下文管理器

`__aenter__` 和 `__aexit__` 用于 `async with`。

```python
class AsyncResource:
    async def __aenter__(self):
        print("获取资源")
        return self

    async def __aexit__(self, exc_type, exc_val, exc_tb):
        print("释放资源")

async def main():
    async with AsyncResource() as r:
        print("使用资源")
```

### (10) 可调用对象

#### 10.1 `__call__`

使实例可以像函数一样被调用。

```python
class Adder:
    def __init__(self, n):
        self.n = n

    def __call__(self, x):
        return x + self.n

add5 = Adder(5)
print(add5(10))   # 15
print(callable(add5))   # True
```

**用途**：装饰器类、状态保持的回调、策略模式等。



### (11) 复制与序列化

| 方法            | 用途                        |
| :-------------- | :-------------------------- |
| `__copy__`      | `copy.copy(obj)`            |
| `__deepcopy__`  | `copy.deepcopy(obj)`        |
| `__getstate__`  | `pickle` 序列化时获取状态   |
| `__setstate__`  | `pickle` 反序列化时恢复状态 |
| `__reduce__`    | 自定义 `pickle` 行为        |
| `__reduce_ex__` | 同 `__reduce__`，带协议版本 |



```python
import copy

class Demo:
    def __init__(self, data):
        self.data = data

    def __copy__(self):
        print("浅拷贝")
        return Demo(self.data)

    def __deepcopy__(self, memo):
        print("深拷贝")
        return Demo(copy.deepcopy(self.data, memo))

d = Demo([1, 2, 3])
d2 = copy.copy(d)
d3 = copy.deepcopy(d)
```

### (14) 小结

#### 按功能分类

| 分类            | 魔法方法                                                     |
| :-------------- | :----------------------------------------------------------- |
| **生命周期**    | `__new__`、`__init__`、`__del__`、`__init_subclass__`、`__set_name__` |
| **字符串表示**  | `__str__`、`__repr__`、`__format__`、`__bytes__`             |
| **属性访问**    | `__getattr__`、`__getattribute__`、`__setattr__`、`__delattr__`、`__dir__` |
| **描述符**      | `__get__`、`__set__`、`__delete__`                           |
| **容器/序列**   | `__len__`、`__getitem__`、`__setitem__`、`__delitem__`、`__contains__`、`__iter__`、`__next__`、`__reversed__`、`__missing__` |
| **比较**        | `__eq__`、`__ne__`、`__lt__`、`__le__`、`__gt__`、`__ge__`、`__hash__`、`__bool__` |
| **算术**        | `__add__`、`__sub__`、`__mul__`、`__truediv__`、`__floordiv__`、`__mod__`、`__pow__`、`__matmul__`、`__divmod__` |
| **反向算术**    | `__radd__`、`__rsub__`、`__rmul__` 等                        |
| **增量赋值**    | `__iadd__`、`__isub__`、`__imul__` 等                        |
| **一元运算**    | `__neg__`、`__pos__`、`__abs__`、`__invert__`、`__round__`、`__floor__`、`__ceil__`、`__trunc__` |
| **类型转换**    | `__int__`、`__float__`、`__complex__`、`__bool__`、`__bytes__`、`__index__` |
| **上下文管理**  | `__enter__`、`__exit__`、`__aenter__`、`__aexit__`           |
| **可调用**      | `__call__`                                                   |
| **复制/序列化** | `__copy__`、`__deepcopy__`、`__getstate__`、`__setstate__`、`__reduce__` |
| **类相关**      | `__class_getitem__`、`__instancecheck__`、`__subclasscheck__`、`__prepare__` |

#### 最佳实践

1.  **优先定义 `__repr__`**，便于调试；`__str__` 可选。
2.  **定义 `__eq__` 时同时定义 `__hash__`**，保持一致性。
3.  **使用 `functools.total_ordering`** 简化比较运算符的定义。
4.  **`__getattr__` 与 `__getattribute__` 区分**：前者只在属性不存在时调用，后者每次都调用。
5.  **`__slots__` 可节省内存**，但会失去 `__dict__`。
6.  **上下文管理器优先于 `__del__`**，用于资源释放。
7.  **`__call__` 让实例可调用**，适合装饰器类和策略模式。
8.  **避免在 `__init__` 中做耗时操作**，可使用工厂方法。

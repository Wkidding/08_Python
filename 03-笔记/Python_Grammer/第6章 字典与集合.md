## 6.1 字典（dict）的定义与操作

字典（Dictionary）是 Python 中重要的**映射类型**（Mapping Type），以 **键-值对**（Key-Value Pair）形式存储数据，键必须唯一且不可变（如字符串、数字、元组），值可以是任意类型。

- **定义**：用花括号 `{}` 包裹，由逗号分隔的 `键: 值` 对组成。
- **核心特性**：
  1. **键（Key）必须唯一**：如果重复赋值，后面的会覆盖前面的。
  2. **键必须是不可变（Immutable）类型**：如字符串、整数、浮点数、元组（`tuple`）；**列表（`list`）和字典不能作为键**（因为它们是可变的，会引发 `TypeError`）。Key不可重复，重复会对原有数据覆盖
  3. **值（Value）可以是任意类型**：数字、字符串、列表、甚至另一个字典都可以。
  4. **有序性**：Python 3.7+ 开始，字典**保持插入顺序**（遍历时按插入顺序输出）。

```
特点：
    可以容纳多个数据
    可以容纳不同类型的数据
    每一份数据是Key-Value键值对
    可以通过Key获取到Value，Key不可重复（重复会覆盖）
    不支持下标索引
    可以修改（增加或删除更新元素等）
```

### 创建字典

```python
# 空字典
empty = {}

# 使用花括号
person = {"name": "Alice", "age": 25, "city": "Beijing"}

# 使用 dict() 构造函数
person2 = dict(name="Bob", age=30, city="Shanghai")
person3 = dict([("name", "Charlie"), ("age", 35)])

# 字典键可以是不可变类型
d = {1: "one", 2: "two", (1, 2): "tuple key"}  # 元组可作为键
# d = {[1,2]: "list"}  # TypeError: unhashable type 'list'
```

### 基本操作：增删改查

#### （1）查（访问值）

| 方式           | 语法                    | 特点                                                         |
| :------------- | :---------------------- | :----------------------------------------------------------- |
| **直接索引**   | `d["key"]`              | 速度快，但**如果键不存在，直接报错 `KeyError`**（开发时需谨慎） |
| **安全获取**   | `d.get("key", default)` | **极力推荐**！键不存在时返回 `None` 或你指定的 `default` 值，不报错 |
| **获取所有键** | `d.keys()`              | 返回一个视图对象（可迭代）                                   |
| **获取所有值** | `d.values()`            | 返回一个视图对象                                             |
| **获取键值对** | `d.items()`             | 返回 `(key, value)` 元组的视图（遍历常用）                   |

#### （2）增 & 改

**语法**：`d[key] = value`

- 如果 `key` **不存在** → 新增一对键值。
- 如果 `key` **已存在** → 覆盖（修改）原来的值。

#### （3）删

| 方式             | 语法                   | 特点                                                        |
| :--------------- | :--------------------- | :---------------------------------------------------------- |
| **删除指定键**   | `del d["key"]`         | 键不存在会报错 `KeyError`                                   |
| **弹出并返回**   | `value = d.pop("key")` | 删除并返回该键的值；可设默认值防报错（如 `pop("x", None)`） |
| **弹出最后一项** | `d.popitem()`          | Python 3.7+ 删除并返回**最后插入**的一个键值对（元组形式）  |
| **清空整个字典** | `d.clear()`            | 清空所有内容，剩下 `{}`                                     |

```python
person = {"name": "Alice", "age": 25}

# 访问值（通过键）
print(person["name"])      # "Alice"
# print(person["gender"])  # KeyError，键不存在会报错

# 添加或修改键值对
person["city"] = "Beijing"   # 新增
person["age"] = 26           # 修改
print(person)   # {"name": "Alice", "age": 26, "city": "Beijing"}

# 删除键值对
del person["city"]
print(person)   # {"name": "Alice", "age": 26}

# pop() 删除并返回对应值
age = person.pop("age")
print(age)      # 26
print(person)   # {"name": "Alice"}

# popitem() 删除并返回最后一个键值对（Python 3.7+ 有序）
person = {"a": 1, "b": 2, "c": 3}
item = person.popitem()
print(item)     # ("c", 3)
print(person)   # {"a": 1, "b": 2}

# clear() 清空
person.clear()
print(person)   # {}
```

### keys() / values() / items()

这些方法返回**视图对象**（View），动态反映字典变化，可转换为列表。

```python
person = {"name": "Alice", "age": 25, "city": "Beijing"}

# 获取所有键
keys = person.keys()
print(keys)           # dict_keys(['name', 'age', 'city'])
print(list(keys))     # ['name', 'age', 'city']

# 获取所有值
values = person.values()
print(values)         # dict_values(['Alice', 25, 'Beijing'])
print(list(values))   # ['Alice', 25, 'Beijing']

# 获取所有键值对（元组列表）
items = person.items()
print(items)          # dict_items([('name', 'Alice'), ('age', 25), ('city', 'Beijing')])
print(list(items))    # [('name', 'Alice'), ('age', 25), ('city', 'Beijing')]

# 视图动态反映字典变化
keys = person.keys()
person["gender"] = "female"
print(keys)           # dict_keys(['name', 'age', 'city', 'gender'])
```

### get() / setdefault() / update()

```python
person = {"name": "Alice", "age": 25}

# get(key, default)：安全获取，不存在返回默认值
print(person.get("name"))           # "Alice"
print(person.get("gender"))         # None
print(person.get("gender", "未知"))  # "未知"

# setdefault(key, default)：若键存在返回对应值，否则设置默认值并返回
person.setdefault("city", "Beijing")
print(person)          # {"name": "Alice", "age": 25, "city": "Beijing"}

person.setdefault("age", 30)   # 键已存在，返回25但不修改
print(person["age"])   # 25

# update()：合并另一个字典或键值对序列
person.update({"job": "Engineer", "age": 26})  # 更新age，新增job
print(person)   # {"name": "Alice", "age": 26, "city": "Beijing", "job": "Engineer"}

# update 也可以接受键值对列表
person.update([("salary", 8000), ("level", "senior")])
print(person)
```

### 遍历字典

```python
person = {"name": "Alice", "age": 25, "city": "Beijing"}

# 遍历键
for key in person:
    print(key, person[key])

# 遍历键值对（推荐）
for key, value in person.items():
    print(f"{key}: {value}")

# 仅遍历值
for value in person.values():
    print(value)
```


## 6.2 字典推导式

字典推导式可以从可迭代对象快速生成字典， 是**列表推导式**的“亲兄弟”，语法几乎一样，但它的产物是字典（用花括号 `{}` 包裹），且必须同时生成**键（Key）**和**值（Value）**

###  核心语法

- **列表推导式**：`[表达式 for 变量 in 可迭代对象]` → 生成列表
- **字典推导式**：`{键表达式: 值表达式 for 变量 in 可迭代对象}` → 生成字典

**关键区别**：字典推导式最前面必须是一个 **`键: 值` 对**，中间用冒号 `:` 隔开。

```python
# 基本语法：{key_expr: value_expr for item in iterable if condition}

# 生成平方映射
squares = {x: x**2 for x in range(5)}
print(squares)   # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# 带条件过滤（只保留偶数）
even_squares = {x: x**2 for x in range(10) if x % 2 == 0}
print(even_squares)   # {0: 0, 2: 4, 4: 16, 6: 36, 8: 64}

# 交换键值
original = {"a": 1, "b": 2, "c": 3}
swapped = {v: k for k, v in original.items()}
print(swapped)   # {1: 'a', 2: 'b', 3: 'c'}

# 从两个列表创建字典
keys = ["name", "age", "city"]
values = ["Alice", 25, "Beijing"]
person = {k: v for k, v in zip(keys, values)}
print(person)   # {"name": "Alice", "age": 25, "city": "Beijing"}
# 进阶：可以直接用 dict(zip(keys, values))

# 嵌套推导式（处理矩阵）
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
row_sum = {f"row{i}": sum(row) for i, row in enumerate(matrix)}
print(row_sum)   # {"row0": 6, "row1": 15, "row2": 24}
```



## 6.3 字典的底层实现（哈希表）

### 哈希表原理简述

字典通过**哈希表**（Hash Table）实现，核心思想：
- 对键调用 `hash()` 函数计算哈希值（整数）
- 哈希值对表大小取模，确定存储位置（桶）
- 解决哈希冲突：Python 采用**开放寻址法**（Open Addressing）

### 哈希与不可变要求

- 键必须是**可哈希**（Hashable）的，即对象在其生命周期内哈希值不变，且支持 `__hash__()` 和 `__eq__()` 方法。
- 不可变类型（`int`, `str`, `tuple`）可哈希；可变类型（`list`, `dict`, `set`）不可哈希。

```python
# 查看哈希值
print(hash("hello"))   # 某个整数
print(hash((1, 2)))    # 可哈希

# 自定义类的实例默认可哈希（id 作为哈希）
class MyClass:
    pass
obj = MyClass()
d = {obj: "value"}   # 可行，但通常不推荐

# 但如果类定义了 __eq__ 而未定义 __hash__，则实例不可哈希
class Unhashable:
    def __eq__(self, other):
        return True
# u = Unhashable()
# d = {u: "test"}  # TypeError: unhashable type
```

### 字典的查找效率

- 平均时间复杂度：**O(1)**
- 最坏情况（大量哈希冲突）：O(n)，但 Python 通过随机化哈希种子和冲突处理减轻风险。

```python
import time

# 比较列表和字典的查找性能（演示）
big_dict = {i: i for i in range(1000000)}
big_list = list(range(1000000))

# 字典查找 O(1)
start = time.perf_counter()
_ = big_dict[999999]
print("字典查找耗时:", time.perf_counter() - start)

# 列表查找 O(n)（最坏情况）
start = time.perf_counter()
_ = big_list.index(999999)  # 实际是O(n)
print("列表查找耗时:", time.perf_counter() - start)
```


## 6.4 集合（set）的定义与操作

集合（Set）是无序、不重复的元素集合，基于哈希表实现，支持数学集合运算。元素必须是**可哈希**的。

### 创建集合

```python
# 空集合（注意 {} 是字典，空集合用 set()）
empty = set()

# 使用花括号
fruits = {"apple", "banana", "orange"}

# 从列表去重
unique = set([1, 2, 2, 3, 3, 4])
print(unique)   # {1, 2, 3, 4}

# 字符串拆分为字符集合
chars = set("hello")
print(chars)    # {'h', 'e', 'l', 'o'}（无序）

# 注意：列表不能作为集合元素
# s = {[1,2]}   # TypeError
```

### 基本操作：增删改查

```python
s = {1, 2, 3}

# 添加
s.add(4)
print(s)   # {1, 2, 3, 4}

# 删除（存在则移除，不存在不报错）
s.discard(2)
print(s)   # {1, 3, 4}
s.discard(10)   # 无影响

# remove（不存在会报错）
s.remove(3)
print(s)   # {1, 4}
# s.remove(10)   # KeyError

# pop() 随机删除并返回一个元素
popped = s.pop()
print(popped, s)   # 可能输出 1, {4}

# clear()
s.clear()
print(s)   # set()

# 成员测试
s = {1, 2, 3}
print(1 in s)   # True
print(4 not in s)  # True

# 长度
print(len(s))   # 3
```

### 集合运算（交集、并集、差集、对称差）

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

# 交集（元素同时属于 A 和 B）
print(A & B)           # {3, 4}
print(A.intersection(B))   # {3, 4}

# 并集（元素属于 A 或 B）
print(A | B)           # {1, 2, 3, 4, 5, 6}
print(A.union(B))      # {1, 2, 3, 4, 5, 6}

# 差集（属于 A 但不属于 B）
print(A - B)           # {1, 2}
print(A.difference(B)) # {1, 2}

# 对称差（属于 A 或 B，但不同时属于两者）
print(A ^ B)           # {1, 2, 5, 6}
print(A.symmetric_difference(B))  # {1, 2, 5, 6}

# 判断子集/超集
C = {1, 2}
print(C <= A)   # True，C 是 A 的子集
print(C.issubset(A))  # True
print(A >= C)   # True，A 是 C 的超集
print(A.issuperset(C)) # True

# 判断是否不相交
print(A.isdisjoint({5, 6}))  # False（有交集 {3,4,5,6}? 实际 A∩{5,6}=空? 不对，A有3,4，但没有5,6，所以A∩{5,6}=空，故True）注意：{5,6}与A没有共同元素，所以True
print(A.isdisjoint({5, 6}))   # True，因为 A 没有 5 或 6
```

### 集合推导式

```python
# 基本语法：{expr for item in iterable if condition}

# 生成平方集合
squares = {x**2 for x in range(10)}
print(squares)   # {0, 1, 4, 9, 16, 25, 36, 49, 64, 81}

# 过滤奇数
odd_squares = {x**2 for x in range(10) if x % 2 == 1}
print(odd_squares)   # {1, 9, 25, 49, 81}

# 提取字符串中唯一字符
text = "hello world"
unique_chars = {c for c in text if c != ' '}
print(unique_chars)   # {'l', 'o', 'h', 'e', 'r', 'd', 'w'}

# 嵌套推导式（提取矩阵中偶数）
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
evens = {num for row in matrix for num in row if num % 2 == 0}
print(evens)   # {8, 2, 4, 6}
```

### 集合的应用

```python
# 去重
words = ["apple", "banana", "apple", "orange", "banana"]
unique_words = list(set(words))
print(unique_words)   # 无序去重

# 查找两个列表的共同元素
list1 = [1, 2, 3, 4]
list2 = [3, 4, 5, 6]
common = set(list1) & set(list2)
print(common)   # {3, 4}
```


## 6.5 frozenset（不可变集合）

`frozenset` 是**不可变集合**，一旦创建不能修改。它是可哈希的，因此可以作为字典的键或集合的元素。

### 创建 frozenset

```python
# 从可迭代对象创建
fs = frozenset([1, 2, 3, 3, 4])
print(fs)           # frozenset({1, 2, 3, 4})

# 空 frozenset
fs_empty = frozenset()
```

### 支持的操作

- 支持所有**不修改**集合的操作：`&`, `|`, `-`, `^`, `issubset`, `issuperset`, `isdisjoint`, `len`, `in` 等
- 不支持修改操作：`add`, `remove`, `discard`, `pop`, `clear`

```python
fs1 = frozenset([1, 2, 3])
fs2 = frozenset([3, 4, 5])

print(fs1 & fs2)     # frozenset({3})
print(fs1 | fs2)     # frozenset({1, 2, 3, 4, 5})
print(fs1 - fs2)     # frozenset({1, 2})
print(fs1 ^ fs2)     # frozenset({1, 2, 4, 5})
print(2 in fs1)      # True
print(len(fs1))      # 3

# 不可变集合可作为字典键
d = {frozenset({1, 2}): "value"}
print(d)   # {frozenset({1, 2}): 'value'}
```

### 与普通集合的对比

| 特性         | `set`            | `frozenset`      |
| ------------ | ---------------- | ---------------- |
| 可变性       | 可变             | 不可变           |
| 可哈希       | 否（不可作为键） | 是（可作为键）   |
| 支持修改方法 | 是               | 否               |
| 适用场景     | 动态集合         | 常量集合、作为键 |

### 综合应用示例

```python
# 统计一段文字中出现的单词及其出现次数（使用字典和集合）
text = "apple banana apple orange banana apple"
words = text.split()
word_count = {}
unique_words = set(words)

for word in unique_words:
    word_count[word] = words.count(word)

print(word_count)   # {'banana': 2, 'apple': 3, 'orange': 1}

# 使用 frozenset 作为缓存键（表示参数组合）
cache = {}
def expensive_function(a, b):
    key = frozenset([a, b])   # 参数组合作为键
    if key in cache:
        return cache[key]
    result = a ** b  # 模拟耗时计算
    cache[key] = result
    return result

print(expensive_function(2, 10))  # 计算
print(expensive_function(10, 2))  # 因为 frozenset 相同，命中缓存（但计算错误，因为 a,b 顺序不同但结果不同？此处仅为演示）
# 注意：实际应使用 (a,b) 元组作为键，这里仅为示例 frozenset 用法
```

- **字典推导式**可快速生成字典。
